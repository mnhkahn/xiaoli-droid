## 真实线上联调

模拟器连接 Fly.io，免费模型列表选择 `nvidia/nemotron-3.5-super-vl:free`，发送用户提供的原始口算照片。完整用例通过，耗时 79.896 秒（包括模型推理），收到 8518 字符的思考过程以及前 10 题完整 Markdown 表格。独立计算与返回表格中的算术结果一致；这不等于独立证明手写识别准确率为 100%。原图与批改内容只保留在忽略目录，不提交仓库。

真实扩展联调用例在最后 ASR 阶段失败。失败前下列断言已通过，但整个用例不计为通过：

- 个性化设置更新与恢复，记忆增删查。
- 实际生成 PDF，服务器提取六位验证码，所选模型回答正确，鉴权预览可读。
- 服务端在指定时间执行任务，模拟器退到后台后收到完成通知。
- 临时会话实际回答、在普通会话列表不可见并可清除。

ASR 配置对应的硅基流动接口返回 HTTP 402 / code 30001，提示账号余额不足；既有 Cyeam ASR 入口也不可用。模拟器内置中文识别数据没有安装，尝试下载未获得完成回调，不能作为已经可用的替代方案。未擅自充值，也没有将假识别结果算成成功。连续语音的 ASR → 模型 → TTS → 继续监听流程等待可用识别服务后重新验收。

## 发布边界

原公开基线 0.1.1 已完成蒲公英重新下载、验签与覆盖安装。本次 0.2.0 在语音和 Actions 完成前只作为预览验证包，不能声称全部 ready。

固定签名与蒲公英 Secrets 已配置；密钥不进入仓库。GitHub Actions 支持 main 预览、手动发布及版本 Tag 发布，代码提交推送后必须实际运行才能验收。普通 APK 更新由系统要求安装确认，不承诺静默升级。Android 默认助理通过系统角色与唤起入口验证；小米 ROM 硬件按键、熄屏热词、后台限制和真机功耗不在本次模拟器验收范围。
