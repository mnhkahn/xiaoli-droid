# 小李手机端范围与验收

2026-11-14：用户已确认前两组功能一次性交付，取消第三组高级能力。0.2.0 已作为预览验证包提供下载，语音识别和 Actions 尚未验收；最终状态以 validation.md 为准。

## 本次范围

| 用户功能 | 实际行为 | 验收要求 |
| --- | --- | --- |
| 日常会话 | 搜索标题和消息、重命名、置顶、归档、回收站恢复、Markdown 导出和系统分享 | 手机交互、重启持久化、设备隔离 |
| 编辑与重新回答 | 保留原会话，新建带上下文的分支；原问题进入可编辑草稿，再确认发送 | 不继承旧授权、不自动重放工具、图片和文档上下文正确 |
| 草稿与重试 | 按服务器、设备、会话保存文字、图片、文档与请求编号；已受理的请求恢复时清理草稿 | 新 ViewModel 恢复、原子写入、失败不丢附件、去重 |
| 图片和文件 | 拍照、相册、分享、粘贴；UTF-8 文本、PDF、DOCX、XLSX 实际解析进入模型输入；原文件下载/分享 | 原图口算、真实 PDF 内容、Office 解析、跨设备不可访问 |
| 回复使用 | Markdown、表格、图片缩放、公式、代码复制、选择/复制/分享、保存到相册 | 实际渲染、MediaStore、私有文件授权 |
| 免费模型 | cyeam 目录搜索、刷新、当前会话选择和新对话默认模型 | 指定 Nemotron 真实请求；不改变微信/飞书默认模型 |
| 联网与工具 | 手动联网搜索开关、可展开的工具状态和耗时、真实检索来源、问题和权限卡片 | 来源来自成功工具结果，不从模型文本推断“已检索” |
| 个性化与记忆 | 自定义说明、记忆开关、查看/修改/删除记忆 | 仅当前配对设备的 Android 命名空间；旧渠道不受影响 |
| 临时会话 | 内存会话，不创建普通会话、Agent 记忆、检查点或工具执行记录；关闭清除 | 服务端普通历史和会话存储中不可见；附件有界并清理 |
| 定时任务 | 一次/每天/每周、时区、编辑、暂停、删除、打开结果会话 | 服务端调度；受理前后重启不重复执行同一次请求 |
| 通知 | 用户开启后，用可停止的前台连接接收完成和待确认状态；点击打开会话 | 后台到达、去重、断线恢复、系统通知权限 |
| 连续语音 | VAD 自动分句、ASR、发送、回复分段朗读、点击打断/继续、语速偏好 | 真实中文合成和识别、取消/前后台、语音焦点 |
| 手机体验 | 系统/浅/深色、系统字号、位置先填入草稿、设备认证应用锁、默认助手入口 | 模拟器；真实系统手势性能和升级后助手角色保留 |
| 发布升级 | 固定签名、下载校验、系统安装、蒲公英、GitHub Actions/Tag | 发布后重新下载、验签、覆盖安装；Actions 只有实际运行后才算通过 |

## 明确边界

- 不做视频、屏幕共享、图像创作/编辑、项目资料库、多设备同步、事件连接器、公开分享链接或原生实时音频。这些属于已取消的第三组。
- 连续语音采用现有 ASR 加系统中文 TTS。原生实时音频未接入。系统没有中文语音数据时需要安装语音数据。
- 文档每个 8 MB，最多 4 个，提取文字每个最多 64000 字。PDF 扫描件不能冒充已读，改发图片；Office 为 DOCX/XLSX，旧二进制 DOC/XLS 不支持。
- 图片每次最多 4 张，压缩后每张最多 3 MB。手机模型历史中的内嵌图片有容量上限，超出时向模型明确说明缺失；原附件保留在私有媒体中。
- 临时内容在本服务内不进入普通持久化路径；文档解析可能使用随解析结束清理的私有临时文件。应用/服务异常退出通过临时会话过期和重新创建回收。第三方模型的保留策略不由本服务控制。
- 回收站是可恢复删除；导出的文本不包含图片/文件访问凭证。应用锁使用系统设备认证，作用于手机界面。
- 后台通知依赖用户开启的前台连接。连接被系统或用户停止时不能保证即时到达；重连后补齐最新状态，不把周期查询描述为推送。
- 按用户要求只做模拟器验证。小米 ROM 的硬件按键、后台限制和熄屏唤醒不声称经过真机验证。
